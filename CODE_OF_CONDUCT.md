# Code of Conduct

## Our commitment

AETHER's project spaces should be welcoming, respectful, and constructive for people with different backgrounds, experience levels, and viewpoints.

## Expected behavior

- Be respectful, patient, and considerate.
- Critique ideas and implementations, not people.
- Explain disagreements with evidence and technical reasoning.
- Give feedback that helps others improve.
- Respect privacy; do not publish another person's credentials, private data, or conversation without permission.
- Accept responsibility for mistakes and correct them constructively.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, deliberate intimidation, sexualized attention without consent, and repeated disruptive or bad-faith behavior are not acceptable.

## Maintainer responsibility

Project maintainers may edit or remove contributions and may restrict participation when needed to protect the community. Concerns should be reported privately through the maintainer's GitHub profile. Do not use a public issue to disclose sensitive personal information.

## Scope

This code applies in AETHER repository issues, pull requests, reviews, and other project spaces where contributors represent the project.

## Attribution

This is a project-specific code of conduct written for AETHER.
