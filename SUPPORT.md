# Support

AETHER is an independently maintained alpha project. There is no paid support channel or guaranteed response time.

## Where to ask

- **Something is broken:** open a [bug report](https://github.com/ghostfacethegreat/aether-agent/issues/new?template=bug_report.yml).
- **You want a capability:** open a [feature request](https://github.com/ghostfacethegreat/aether-agent/issues/new?template=feature_request.yml).
- **You are unsure whether something is implemented:** check [known limitations](docs/KNOWN_LIMITATIONS.md), the [feature comparison](docs/HERMES_COMPARISON.md), and the relevant guide under `docs/`.

Before opening an issue, search [existing issues](https://github.com/ghostfacethegreat/aether-agent/issues) to avoid duplicates.

## What to include in a support request

Include the AETHER commit or version, operating system and version, Python version, provider and model (never the key), the exact command, expected behavior, actual behavior, and a small reproducible example. Include sanitized logs only when useful.

**Never post API keys, access tokens, cookies, private prompts, private project files, or unredacted session databases.** Remove personal paths and identifiers from logs before sharing them.

## Project status

AETHER is alpha software. Features can change, provider quotas and model IDs can change, and some roadmap items are not implemented yet. Read the [README](README.md) and [release roadmap](docs/RELEASE_ROADMAP.md) before relying on it for important work.
