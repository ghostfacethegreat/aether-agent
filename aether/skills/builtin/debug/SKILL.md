# Debugging checklist

1. Capture the exact error, command, input, and environment.
2. Reproduce with the smallest possible input.
3. Form one hypothesis at a time and test it.
4. Inspect logs and relevant source before changing code.
5. Apply the smallest fix that addresses the root cause.
6. Run the narrowest test first, then the full relevant suite.
7. Report what was observed, what was changed, and what remains uncertain.
